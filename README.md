# DJ RUSTY NUTTZ — Official Website

One-page hard trance DJ website with biography, SoundCloud player and booking enquiry form.

## Files

- `index.html` — main website (already committed)
- `logo.png` — transparent logo (**upload this image**)
- `background.jpg` — static black-and-white background (**upload this image**)

Place all three files in the **root** of the `main` branch with these exact lowercase filenames. The website refers to the two image filenames directly.

## Bookings

The booking form prepares an email addressed to rusty_nuttz@outlook.com using the visitor's default mail application. The visitor must press Send. For automatic submissions, configure a form-processing service.

## Free publishing

In repository Settings → Pages, choose **Deploy from a branch**, select **main** and **/(root)**, and save. The published page will normally be available at https://proveitdj.github.io/rustynuttz/ once GitHub Pages is enabled and finishes deploying.
